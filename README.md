# DVa: Data Visualisation Planning

DVa helps you think through an infographic or data visualisation before it reaches a designer,
then turns your answers into a PDF brief.

It began as a pen-and-paper form created by Marco Zaplan and Eddie Shin at the Southeast Asia
Open Data Innovation Week (November 2016), part of the Web Foundation's Open Data Innovation Toolbox.
This is the 10th anniversary edition.

## The eight questions

1. Why do I want to make this?
2. What data do I have to deliver my message?
3. Who should I target?
4. What's an interesting, relevant fact my users need to know?
5. What is the story I want to deliver?
6. What information do I want to visually present?
7. What should it look like? (layout, fonts, colour scheme, title)
8. How do I reach my users?

Progress can be saved as JSON from the sidebar and loaded back later.

## Run locally

    pip install -r requirements.txt
    streamlit run app.py
